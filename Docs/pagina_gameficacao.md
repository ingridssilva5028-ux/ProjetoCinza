# Página de Gameficação
Essa é a página de Gameficação de um site de trocas de itens colecionáveis;
O usuário acessa essa página depois de entrar no seu perfil e clicar em um botão que redireciona para a página de gameficação.

## Instruções para criação
- Leia o arquivo contexto_protti.md para entender o contexto do site, encontrado na pasta `Docs`.
- Crie um arquivo HTML com o nome gameficacao.html.
- Crie um arquivo CSS com o nome gameficacao.css.
- Siga as etapas a seguir para estruturar a página:

### Navbar
A barra de navegação é compartilhada entre as páginas. Por hora, cada página vai criar do zero sua Navbar.

A Navbar é composta por:
- Logo do site;
- Campo de pesquisa;
- Botão de notificação;
- Botão de mensagens;
- Botão de Login/Cadastro.

### Título
O título contém 3 elementos:
- Ícone de troféu;
- Título 'Gameficação';
- Texto descritivo 'Acompanhe seu progresso e conquiste reconpensas!'

### Painel do Perfil
O painel do perfil é, estruturado da seguinte forma:
- Foto do usuário;
- Nome do usuário;
- Texto do nível atual;
- Barra de XP;
- Texto com a quantia de XP e quanto falta para o próximo nível 'quantia_atual/quantia_total XP';
- Texto com a quantia faltante para próximo nível 'Faltam X XP para o próximo nível';
- Painel de status:
    - XP atual;
    - Nível atual;
    - Missões Concluídas;
    - Conquistas ganhas;
    - Badges ganhas.

### Painel das Missões
O painel de missões é composto por:
- Ícone de tiro ao alvo;
- Título 'Missões';
- Botão 'Ver todas';
- Menu com 2 abas:
    - 'Diárias';
    - 'Semanais'.
    - Cards as missões em lista.

### Painel do Ranking de Colecionadores
Estrutura:
- Ícone de troféu;
- Título 'Ranking dos Colecionadores';
- Botão 'Ver ranking completo';
- Cards dos usuários em lista:
    - Número da colocação;
    - Foto;
    - Nome;
    - Quantidade XP.

### Painel de Madalhas
Estrutura:
- Ícone de estrela;
- Título 'Medalhas';
- Botão 'Ver todas';
- Cards das medalhas:
    - Ícone da medalha;
    - Nome;
    - Descrição da conquista;
    - Ícone de completude da medalha (certinho) OU barra de progresso para finalizar.

### Rodapé
O rodapé também será compartilho por todas as páginas, mas por hora cada página tem o seu.

O rodapé tem uma cor diferente do fundo do site.

Há o ano de criação do site centralizado.
