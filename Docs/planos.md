# Página de Planos
## Introdução
Crie uma página de planos/preço em HTML e CSS
Faça o código organizado e fácil de editar 
Use icones com Font Awesome ou outra biblioteca de icones, caso necessario.
O resultado precisa ser moderno, limpo e profissional 

# Estrutura da página
## Cabeçalho
Crie no topo uma barra horizontal azul-marinho escura, ocupando toda largura da tela.

## Caracteristicas:
Fundo azul marinho/degrade discreto 
Altura aproximada de 100px.
Alguns elementos decorativos em azul no topo 
Pode utilizar formas geometricas simples feitas com css para reproduzir os elementos decorativos
Mantenha o cabeçalho visualmente elegante e minimalista

## Titulo principal
Logo abaixo do cabeçalho, crie uma seção centralizada

Titulo: "PLANOS"
Caracteristicas:
- Letras grandes
- Fonte moderna e pesada
- Cor azul marinho
- Texto centralizado

Ao lado do titulo, coloque pequenos elementos decorativos horizontais em azul

Abaixo coloque, coloque pequenos elementos decorativos em forma de listra na horizontal na cor azul

Abaixo do titulo coloque:
"Escolha o plano ideal para voce e evolua sem limites."
 - Fonte menor 
 - Cor cinza 
 - Centralizado

 ## Area dos planos
 
 Crie 3 cards lado a lado:

 - Card 1: Plano básico 
 - Card 2: Plano itermediario
 - Card 3: Plano avançado 
 
 No desktop, os tres cards devem ficar alinhados horizontamente e possuir aproximadamente a mesma altura.

 Em telas menores, eles devem se reorganizar verticalmente usando CSS responsivo

## Estilo visual
Use:
 
- Fundo geral branco ou cinza muito claro.
- Azul principal semelhante ao da referencia
- Azul marinho para titulo
- Roxo para plano intermediario
- Laranja para o plano avançado
- Cinza para textos scundarios
- Bordas arredondadas
- Sombras suaves
- Cards com aparencia moderna
- bastante espaço interno
- tipografia moderna e facil de ler

Sugestao de fonte:
Inter, poppins ou montserrat

Use uma fonte consistente em toda pagina 

## Detalhes dos cards
 os cards devem:

 - ter bordas arredondadas
 - possuir uma pequena borda colorida no topo
 - ter uma sombra suave
 - ter padding confortavel
 - ter altura visual semelhante
 - manter o botao proximo  a parte inferior do card
 - os beneficios devem ficar alinhados 
 -  os icones e check devem acompanhar a cor do plano
 - o preço deve ter bastante destaque.

 No card avançado:
 - Use uma borda laranja mais evidente.
 - adicione uma sombra laranja bem suave.
 - A etiqueta "★Mais popular" deve ficar acima do acard.
 - o card pode ser ligeiramente mais destacaddo que os outros. 

 ## Responsividade
 
 - A pagina precisa funcionar perfeitamente em:
 - computador
 - notebook 
 - tablet 
 - celular 

 ## Hover 
  Adicione efeitos suaves ao passar o mouse nos cards e botoes

  Cards:
  - leve elevação
  - sombra um pouco maior 
  - transiçao suave 

  Botoes:
  - pequena mudança de tonalidade
  - cursor pointer
  - transiçao suave

  Não exagere nos efeitos.
